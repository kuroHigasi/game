# LOADステータスにおける遷移イベント

| NO | イベントID        | 画面要素ID | 遷移先（固定/可変） | 説明                  |
|:--:|:--------------|:-------|:-----------|:--------------------|
|    | LOAD_COMPLETE | -      | 可変         | ロードが完了したため次画面へと進む   |
|    | LOAD_ERROR    | -      | 可変         | ロード時にエラーが発生したためリトライ |

> ローディング画面では、ゲームのロードが完了した際にLOAD_COMPLETEイベントが発生し、次の画面へと遷移します。また、ロード中にエラーが発生した場合はLOAD_ERRORイベントが発生し、ユーザーにリトライを促すことができます。
