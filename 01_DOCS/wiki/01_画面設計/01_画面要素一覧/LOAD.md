# ローディング画面要素一覧
- ローディング画面に配置される要素の一覧を以下に示します。
- ステータス遷移有無は、データのロード状態に依存する。
- 画面要素IDは、実装時に使用される識別子であり、命名規則に従って一意である必要があります。
- 以下の表は、ローディング画面に配置される要素のID、種別、ステータス遷移の有無、および名称を示しています。

### ローディング画面要素一覧
| NO | 画面要素ID     | 種別   | ステータス遷移有無 | 名称          |
|:--:|:-----------|:-----|:----------|:------------|
|    | LOAD_ICON  | アイコン | 無         | ゲームのアイコンを表示 |
|    | LOAD_TIPS  | テキスト | 無         | ゲーム情報を表示    |
|    | LOAD_ERROR | テキスト | 無         | エラー表示       |
